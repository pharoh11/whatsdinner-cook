# What's Dinner — recipe viewer

A single page that draws a recipe carried in its own address, after the `#`. Browsers never send that part of an address to a website, so this site never sees, receives or stores any recipe.

- `index.html` — the viewer.
- `test.html` — HomeView address test (made-up recipes).
- `control.html` — the same test recipe as an ordinary page, for comparison.
